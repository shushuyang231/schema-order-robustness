# TMLR submission checklist

Checked against the official TMLR author guide and FAQ on 2026-07-24.

- [x] PDF generated with the official `tmlr.sty` review-mode template.
- [x] Author names, affiliations, acknowledgments, and identifying links are
  absent from the review PDF.
- [x] The first page discloses generative-AI assistance, as required by the
  TMLR FAQ.
- [x] No page geometry, font, or style-file parameters are modified.
- [x] References follow the supplied `tmlr.bst` style.
- [x] A Broader Impact / Ethics section states benefits, risks, and mitigations.
- [x] Supplement is an anonymized ZIP and remains below TMLR's 100 MB limit.
- [x] Supplement excludes credentials, restricted gold, raw provider
  responses, downloaded benchmark contexts, and vendor repositories.
- [x] Paper distinguishes prompt-based schema guidance from native structured
  decoding and tool calling.
- [x] Gateway aliases remain explicitly unverified.
- [x] Negative practical replications are reported.
- [ ] Authors must complete active OpenReview profiles, conflicts, funding,
  human-subjects declarations, and Action Editor suggestions before upload.
- [ ] Replace the placeholder OpenReview URL, month, and year only for an
  accepted or preprint version; do not de-anonymize the review submission.
